# Configuration

Upon first startup, Gray Meadows Shell will drop a TOML configuration file in `~/.config/gray-meadows/config.toml`. In order to configure the functionality of the shell, you should edit this file.

If you want to know everything that is configurable, the configuration is extensively documented [here](https://github.com/Inparsian/gray-meadows-shell/blob/master/config.example.toml). There you will find every valid configuration option along with comments describing what they do, and the valid options for it.
